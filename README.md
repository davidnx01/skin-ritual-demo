# Fabulous Beauty — neoficiálny návrh redizajnu (Darwon)

Toto je **neoficiálny návrh redizajnu** e-shopu [fabulousbeauty.eu](https://fabulousbeauty.eu). Nejde o web Fabulous Beauty ani FB Clinic — je to ukážka dizajnu vytvorená agentúrou Darwon, bez súvislosti so skutočným prevádzkovateľom.

- Len 2 statické HTML stránky: `index.html` (homepage) a `produkt.html` (produktová landing page pre Auré Révive).
- Čistý HTML/CSS/JS bez backendu — košík, filtre a galéria sú len klientová ukážka správania, nič sa neodosiela ani neukladá.
- Stránky majú `<meta name="robots" content="noindex, nofollow">` a viditeľný pruh „Neoficiálny návrh redizajnu" v hlavičke.
- Viacero miest v dizajne má poznámky (`data-note`, prepínač „Poznámky k návrhu“) — ide o otvorené otázky na overenie so skutočnou klinikou (čísla, zloženie, objem produktu, recenzie sú len vzorové).

Na žiadosť skutočného prevádzkovateľa bude repozitár a nasadenie okamžite odstránené.
